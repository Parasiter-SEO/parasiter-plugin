# Images by platform

| Platform | Images | Format notes |
|---|---|---|
| Medium / LinkedIn / blog platforms | 3–6 | Cover 16:9 (~1400×788); inline 16:9 or 4:3 |
| Forums | 2–5 | Hosted externally (image host), moderate size; forum may resize |
| Reddit | 0–2 | Native, unpolished look; no ad-style banners |
| PDF | 2–4 light images | Keep file small; cover + 1–2 tables/infographics |
| Press release | 1–2 if the editor allows | Neutral product/editorial image |
| Raisely / fundraising CMS | Cover only (usually) | Cover is the only image — make it count |
| Facebook posts | 1 per post, series | 1:1 or 4:5; link and deal stay in text |
| YouTube | Thumbnail 16:9 (1280×720) | Large text, face/product, high contrast |
| Pinterest | 2:3 vertical (1000×1500) | Text overlay with the benefit |

Alt text on every image: what it shows + product name, plain language.
