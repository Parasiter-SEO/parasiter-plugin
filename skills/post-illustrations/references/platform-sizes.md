# Images by platform

**Default for every article image: horizontal, full article width, JPG ~700 px wide (16:9 → 700×394), quality ~80 — light files, fast pages.** Only the formats below that are not articles differ.

| Platform | Images | Notes |
|---|---|---|
| Medium / LinkedIn / Pressbooks / blog platforms | cover + 3–6 | 700 px horizontal; upload the file |
| Forums | cover + 2–5 | most forums take images only by link: host the image (see below) and paste the URL |
| Gamma, document hosts, PDF | 2–4 | keep the file small; infographics carry the facts |
| Reddit | 0–2 | native, unpolished look; no ad-style banners |
| Press release | 1–2 if the editor allows | neutral product image |
| Raisely / fundraising CMS | cover only | the cover is the only image — make it count |
| Facebook posts | 1 per post, series | 1:1 or 4:5; link and deal stay in text |
| YouTube | thumbnail 1280×720 | large text, product, high contrast |
| Pinterest | 2:3 vertical (1000×1500) | the only vertical exception |

## Hosting images by link

Many platforms don't accept uploads and ask for an image URL. Put the images where they get an open direct link (ending in .jpg): the user's own site (a media folder), or an image host that gives direct links. Check the link opens in a private window before pasting it. Keep a copy of every image with the article text.

No alt text: the plugin doesn't write it (the user's choice).
