# Platform formats

Same sales logic everywhere (author → problem → solution → bridge → facts → decision → CTA); the format adapts to the platform. Before publishing, look at what already ranks on the platform and copy its native style and limits.

| Platform | Length | Tone | Formatting / limits |
|---|---|---|---|
| Medium, LinkedIn, blog-type platforms | 1,500–2,000+ words | Expert or real-user blog post | Full structure, tables, images, TOC |
| Forums | Medium; follow forum limits | Native forum user/expert, first person, friendly, asks for replies | Forum editor (often BBCode), images hosted externally, check keyword filters and moderation; unique title matters most; prepare 2–5 own replies in the thread |
| Reddit / Quora | Short to medium | Genuine question/answer, community voice | No sales voice; follow subreddit rules |
| PDF (upload platforms) | ~3,000 words | Research paper / analysis | Clean, standard document look (no flashy design); few light images; TOC/bookmarks; key benefits and main links on the first screens; mobile-readable; soft CTAs |
| Press release (GlobeNewswire, Access Newswire, etc.) | 2,000–3,000 words | Independent expert/journalist, educational | Neutral language, avoid "best"/hype; facts, comparisons, links to credible sources; images if the editor allows |
| Raisely / fundraising CMS | Under ~1,000 words | Personal blog of an expert/user | Usually no inline images (use the cover image); emojis, lists, links; compact spacing; line-by-line comparisons |
| Facebook page/group posts | Short | Brand fan / expert | Link + deal in the first lines; visuals; hashtags; series of posts on different benefits |
| YouTube description | 1,000–3,000 characters | Reviewer | Affiliate link + deal + key selling point in the first 3 lines; then full description, timestamps, hashtags |

## Titles that rank and get clicks

Personal and experience-based: "Honest Review", "My 90-Day Trial" (only if real), "How I Tested…", "Best … in 2026 — Full Comparison", "[A] vs [B]: Which One to Buy". Include the main keyword. On forums the title must stand out from dozens of similar posts.

## Keep copies

Save every published text (and HTML where possible). Platforms delete posts; a saved copy can be republished elsewhere quickly. On forums only the title must be unique.
