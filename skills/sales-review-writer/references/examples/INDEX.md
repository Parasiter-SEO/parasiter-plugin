# Visual references — example pages by format

Screenshots of real, working sales pages and the author's content-model infographics. Links to live parasite pages die (platforms delete posts), so every reference is stored as an image in this folder; a link is added only as an extra.

## How to use (for the skill)

1. Before drafting, pick 1–2 references whose **format** and **platform** match the brief.
2. Open the image(s) and tell the user which reference you follow and what you take from it (layout, order of blocks, table style, where CTAs sit, visuals).
3. Copy the **structure and visual approach**, never the text, the product claims or the people in the screenshot.
4. If no reference fits, say so and follow `../article-structure.md`.

Each reference is labelled as a structural example. Testimonials, doctors, before/after photos, prices and results visible in screenshots are part of the layout only — they are not facts and must not be reused or imitated as real.
