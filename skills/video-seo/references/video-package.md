# Video package — checklist and score

Used before filming (the package) and after publishing (the check). One main query per piece.

## Long video (YouTube) — 100 points

| Element | What good looks like | Points |
|---|---|---|
| Query fit | One main query that has search demand (a video block in Google or suggestions on YouTube); the video answers it | 10 |
| Title | Query near the start, a clear promise, ~60 characters visible, matches the content | 15 |
| Hook | Query and promise said in the first 15 s; the answer starts fast | 10 |
| Description — first 2 lines | Query + short answer; no links-only or hashtags-only opening | 10 |
| Description — body | What it covers, 2–3 related queries in natural sentences, links (hub, offer, disclosed affiliate), 2–3 hashtags | 5 |
| Chapters | Timestamps from 0:00, 4–8 chapters, each named as a sub-query | 10 |
| Captions | Correct captions (uploaded or corrected auto) — the spoken words are searchable | 10 |
| Thumbnail | One subject, ≤4 words readable small, matches the title | 10 |
| Playlist and end screen | In a search-topic playlist; end screen to the next relevant video | 5 |
| Pinned comment and CTA | Next step: link, next video, a question | 5 |
| Indexed and found | Indexed in Google within 14 days; appears for the query in Google or YouTube search | 10 |

## Short (YouTube Shorts, Reels, TikTok, Facebook Reels) — 100 points

| Element | What good looks like | Points |
|---|---|---|
| Query fit | A query people search in the app or Google; one idea per short | 15 |
| Spoken keyword | Query said in the first 2 s | 15 |
| On-screen text | Query or topic as text in the first frames | 15 |
| Caption | Query in the first line, a variant, 3–5 specific hashtags | 15 |
| Cover | Topic in words, readable in the grid | 10 |
| Account settings | Instagram: professional account and the search-engine setting on; public account | 10 |
| Alt text / description | Instagram alt text with the query; Facebook description | 5 |
| Path | To the long video, profile link, or pinned comment | 5 |
| Indexed and found | In Google or in-app search for the query within 14 days | 10 |

## Pinterest pin — checklist

Title with the query · two-sentence description with the query and a variant · vertical 1000×1500 image or video · destination link working · board named by search topic · the creator's account claimed website if they have one.

## Reading the score

85–100 ready · 70–84 fix the medium items · under 70 fix before publishing (or edit after: title, description, chapters, captions and pinned comment can all be changed later; spoken words and on-screen text can't).
