# Query modifiers and the SERP gap check

## Seven modifier clusters

| Cluster | Example modifiers | Commercial strength |
|---|---|---|
| Comparison | vs, versus, better than, alternative, which one | High |
| Distrust | scam, legit, complaints, problems, worth it | High |
| Purchase | discount, coupon, price, shipping, warranty, return policy | Highest |
| Package | standard vs deluxe, kit contents, accessories, bundle | High |
| Experience | after 6 months, long-term, real users, my results | Medium–high |
| Platform | reddit, forum, discussion, user reviews | Medium |
| Evidence | clinical study, evidence, testing methodology | Often researchers, not buyers |

Do not treat all modifiers as equally commercial. "Discount" and "vs" bring buyers; "clinical study" often does not.

## SERP check before writing

1. Open Google in the target country. Check **mobile and desktop**.
2. Note what is there: AI Overview, Reddit/forums (Discussions and forums block), videos, shopping blocks, manufacturer pages, news/press releases, PDFs.
3. Ask: **which buyer question is still not answered well here?** That gap is the topic.
4. Check the chosen platform: does it allow this format and links?
5. Drop the topic if there is no unique added value and no clear commercial action.

Note: appearing in AI Overview is not the same as getting commercial clicks. Every page needs a reason to click after the AI answer.
