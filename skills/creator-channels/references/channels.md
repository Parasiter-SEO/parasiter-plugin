# Channels — what makes each one findable (checked 2026-10-29)

Search rules and settings change; say "as of [date]" and let `video-seo-checker` confirm what is live.

## Where creators' content shows in Google now

- **Short videos** block: YouTube Shorts, TikTok, Instagram Reels (Google also has a "Short videos" filter).
- **Videos** results and **Key moments** (chapters) for YouTube. Video mode shows only pages where the video is the main content.
- **Perspectives** and **Discussions and forums**: Reddit (in about 85% of these blocks), Facebook public groups (~38%), Quora (~32%), YouTube and TikTok in Perspectives (Ahrefs, 08/2026).
- **Instagram**: since 10 July 2025 Google and Bing index public photos, videos, carousels and Reels of **professional accounts (business or creator) of adults (18+)**; personal and private accounts are not included. Posts already rank.
- **Pinterest**: pins in Google Images and web results; reports in 2026 of pins dropping from search — test with the creator's own queries.

## YouTube (official YouTube Help, checked 2026-10-29)

| Check | Good |
|---|---|
| Channel name and handle | Name + niche word if the name alone says nothing ("Anna · Home Workouts") |
| About / description | First line: what the channel is about in searchable words; links to the hub and the money link |
| Banner and photo | Present; banner says the topic and upload rhythm |
| Playlists | Named by search topic ("Kettlebell workouts for beginners"), not "Videos 2025" |
| Titles | 1–2 main keywords in the title (YouTube's own advice), the promise, ~60 visible characters |
| Description | The first lines say what the video is about (shown in search); keywords in natural sentences |
| Chapters | Timestamps in the description, each on its own line, in order from 0:00, with a label — Google uses them for Key moments |
| Tags | Minimal role in discovery (YouTube's words); only for common misspellings |
| Captions | Correct captions (spoken words become searchable text) |
| Thumbnails | Readable at small size, match the title |
| Shorts | The topic said and shown in the first seconds; title / caption with the query |

## Instagram

| Check | Good |
|---|---|
| Account type | **Professional (creator or business)** — needed for Google indexing |
| Setting | Settings → Privacy → **"Allow public photos and videos to appear in search engine results"** — on (default for eligible accounts; check it, someone may have turned it off) |
| Name field | Name + niche keyword (the name field is searchable in Instagram) |
| Bio | Topic in words, who it's for, one CTA, link (hub or link page) |
| Highlights | Named by topic |
| Posts and Reels | Query in the first line of the caption, said in the first seconds, shown as on-screen text; alt text with the query; 3–5 specific hashtags |

## TikTok

| Check | Good |
|---|---|
| Account | Public (no separate "search engines" setting found as of 10/2026) |
| Name and bio | Niche keyword in the name, topic in the bio, link when available |
| Videos | Keyword in the caption, as on-screen text and spoken (TikTok search reads all three — from creator guides, not an official TikTok document) |
| Hashtags | 3–5 specific, not generic lists |
| Playlists | By topic where available |

## Facebook

| Check | Good |
|---|---|
| Page / professional mode | Public, category set, About with the topic and link |
| Posts and Reels | Public; the query in the first line; video description filled |
| Groups | Public groups appear in Google's "Discussions and forums" — a creator's public group around the niche is a strong asset |

## Pinterest

| Check | Good |
|---|---|
| Account | Business account, website claimed if the creator has one |
| Boards | Named by search topic, with descriptions |
| Pins | Title and description with the query, vertical 1000×1500, link to the video / post / hub |

## LinkedIn, X, Threads, Medium, Substack, podcast

Name + topic in the headline or bio, the hub link, posts that answer a query in the first lines with the video embedded or linked. Podcasts: episode titles with the query and show notes with chapters and links.

## Consistency across channels

Same name and photo, the same one-line description of the topic, every channel linking the hub, the hub linking every channel.
